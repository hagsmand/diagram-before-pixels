Fill-in order:
  1. TITLE  2. actors across the top  3. phases down the left, in time order
  4. one ██ block per action, in the owning actor's column
  5. durations or gates where they matter

The value of this pattern is handoffs — every phase where the ██ moves columns is a
handoff. Make sure each one is unambiguous about who acts next.
